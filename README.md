# Jarvis — Голосовой ассистент для Windows

Голосовой ассистент на русском языке для Windows. Работает локально (без интернета) для базовых команд, использует OpenAI как опциональный AI-fallback для сложных запросов.

## Возможности

- Управление приложениями — открыть/закрыть Chrome, Telegram, Discord, Steam и другие
- Открытие сайтов и поиск в браузере
- Управление окнами — свернуть, развернуть, прикрепить, разделить экран
- Управление громкостью и медиа (play/pause/next/prev)
- Управление презентациями (следующий/предыдущий слайд)
- Задачи, таймеры и напоминания
- Погода, дата и время
- Сценарии — цепочки команд одной фразой
- AI-режим на базе GPT-4o / GPT-4o-mini (опционально)
- Активация по wake-word «Джарвис» или кнопкой **F6** (push-to-talk)

## Требования

- **Windows 10 / 11** (64-bit)
- **Python 3.11**
- Микрофон

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/<ваш-username>/jarvis.git
cd jarvis
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Скачать модель распознавания речи

Скачайте русскую модель Vosk и распакуйте её в папку `models/`:

**[vosk-model-ru-0.42](https://alphacephei.com/vosk/models/vosk-model-ru-0.42.zip)** (~1.8 GB)

После распаковки структура должна быть:
```
models/
└── vosk-model-ru-0.42/
    ├── am/
    ├── conf/
    ├── graph/
    └── ...
```

### 4. Запустить приложение

```bash
python -m gui.app
```

## Настройка

### Микрофон

В GUI откройте **Настройки → Аудио** и выберите нужный микрофон из списка. После выбора нажмите **Старт** для перезагрузки модели.

### AI (опционально)

Для AI-режима нужен API-ключ OpenAI:

1. Получите ключ на [platform.openai.com](https://platform.openai.com)
2. В GUI откройте **Настройки → AI**, вставьте ключ и включите AI
3. Рекомендуемая модель: `gpt-4o-mini` (быстрее и дешевле) или `gpt-4o` (умнее)

Без ключа ассистент работает полностью офлайн для всех локальных команд.

### Приложения и сайты

Пути к приложениям и список сайтов настраиваются в GUI (**Настройки → Приложения / Сайты**) или напрямую в `src/jarvis/config.json`.

## Использование

1. Запустите `python -m gui.app`
2. Нажмите кнопку **Старт** — дождитесь загрузки модели (~2 минуты)
3. Скажите **«Джарвис»** — ассистент ответит и будет ждать команду
4. Дайте команду: _«открой браузер»_, _«какая дата»_, _«таймер на 5 минут»_ и т.д.

Альтернативно: удерживайте **F6** (push-to-talk) вместо wake-word.

После каждой успешной команды ассистент остаётся активным **10 секунд** — можно говорить следующую команду без повторного «Джарвис».

## Структура проекта

```
jarvis/
├── gui/
│   └── app.py              # Главное окно (PySide6)
├── src/jarvis/
│   ├── engine.py           # Основной оркестратор
│   ├── nlu.py              # Распознавание команд (правила)
│   ├── executor.py         # Исполнение команд
│   ├── vosk_asr.py         # Распознавание речи (Vosk)
│   ├── openai_client.py    # OpenAI клиент
│   └── config.json         # Конфигурация
├── models/                 # Vosk-модели (не включены в репо)
├── requirements.txt
├── КОМАНДЫ.md              # Список команд
└── README.md
```

## Сборка .exe

```bash
scripts\build_exe.bat
```

Собранный файл появится в папке `dist/`.

## Заметки

- Модель Vosk не включена в репозиторий из-за размера — скачайте отдельно (шаг 3)
- Picovoice (альтернативный wake-word движок) требует отдельного ключа; без него используется текстовый матчинг через Vosk — работает нормально
- `config.json` содержит пути к приложениям — отредактируйте под свою систему
- Данные (задачи, таймеры, история) хранятся в `~/.jarvis/`

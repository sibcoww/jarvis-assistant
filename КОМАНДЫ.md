# Команды Джарвиса

## Активация

| Фраза | Описание |
|-------|----------|
| `Джарвис` | Разбудить ассистента, ожидать команду |
| `Джарвис, открой браузер` | Wake-word + команда в одной фразе |

После активации движок ждёт следующую команду **10 секунд** без повторного произнесения wake-word (continuous mode). Push-to-talk: **F6**.

## Сценарии

Запустить заранее настроенную цепочку действий.

| Фраза | Сценарий | Действия |
|-------|----------|----------|
| `рабочий режим` | Работа | VS Code + Chrome |
| `запусти сценарий игровой` | Игра | FACEIT Anticheat + faceit.com |

Сценарии настраиваются в **Настройки → Сценарии** в GUI или в `config.json → scenarios`.

## AI (умный режим)

Если команда не распознана локально — передаётся в **GPT-4o-mini** (при включённом AI в настройках).

**Что умеет AI-режим:**
- Отвечать на вопросы ("сколько будет...", "кто такой...", "объясни...")
- Открывать нужные сайты по смыслу ("открой что-нибудь про Python")
- Искать в браузере
- Разбирать контекстные фразы ("открой этот сайт", ссылки из диалога)
- Понимать естественный язык для задач/таймеров/напоминаний

AI включается в **Настройки → AI** или в `config.json → ai.enabled: true`.

## Синонимы

Джарвис понимает разные формы слов через таблицу синонимов. Примеры:

| Что сказать | Что откроет |
|-------------|------------|
| `хром`, `браузер`, `chrome` | Google Chrome |
| `телеграм`, `телеграмм`, `телеграмму` | Telegram |
| `дискорд`, `discord` | Discord |
| `обс`, `obs` | OBS Studio |
| `ворд`, `word`, `майкрософт ворд` | Microsoft Word |
| `эксель`, `excel`, `microsoft excel` | Microsoft Excel |
| `зона`, `зону`, `зончик`, `зонка` | Zona |
| `фейсит античит`, `фейсит антикит` | FACEIT Anticheat |
| `вк`, `вк плэй`, `вк плей` | VK Play |
| `энидеск`, `эни деск` | AnyDesk |
| `юбисофт`, `ю плей` | Ubisoft Connect |

Добавить свои синонимы: **Настройки → Синонимы** в GUI или `config.json → synonyms`.
